About

Your Minecraft setup,
all in one place.

Juke Client brings Minecraft version management, isolated game profiles, Microsoft sign-in, supported mod loaders, mod discovery, and launching together in one desktop app.

Features

Everything around the game.

↗

Account & Launch

Sign in with Microsoft, check the associated Minecraft Java profile, and launch Vanilla, Fabric, Forge, NeoForge, or Quilt.

▦

Profile Management

Keep game versions, mods, resource packs, shaders, and worlds in separate profiles.

⌁

Environment & Tools

Choose or download a compatible Temurin Java runtime, check Minecraft server status, and read official release news.

Privacy & Security

Your account stays yours.

Microsoft sign-in opens in a separate window. The launcher stores settings and profiles locally, and uses Electron safeStorage for refresh tokens when operating-system secure storage is available. Juke Client does not store your Microsoft password or bypass Minecraft account ownership.
