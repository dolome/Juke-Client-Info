# JUKE CLIENT

**Dodge the setup. Get into the game.**  
A desktop launcher for Minecraft: Java Edition  
*Windows · macOS · Linux*

*Juke is a small nod to an evasive move.*

## About

Juke Client brings Minecraft version management, isolated game profiles, Microsoft sign-in, supported mod loaders, mod discovery, and launching together in one desktop app.

## Features

- **Account & Launch:** Sign in with a Microsoft account, check the associated Minecraft Java profile, and launch Vanilla, Fabric, Forge, NeoForge, or Quilt.
- **Profile Management:** Keep game versions, mods, resource packs, shaders, and worlds in separate profiles.
- **Environment & Tools:** Choose or download a compatible Temurin Java runtime, check Minecraft server status, and read official release news.

## Privacy & Security

Microsoft sign-in opens in a separate window. The launcher stores settings and profiles locally, and uses Electron `safeStorage` for refresh tokens when operating-system secure storage is available. Juke Client does not store Microsoft passwords or bypass Minecraft account ownership.

For technical privacy details, see [PRIVACY.md](PRIVACY.md).

## Project Status

Juke Client is under active development. Public downloads are not available yet. The source code is kept in a private repository; this page contains project information and documentation only.
